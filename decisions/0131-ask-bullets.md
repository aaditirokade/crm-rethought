# 0131 · Ask answers in bullets; the next move in rose

**Date:** 2026-11-19

**Decision:** an answer that names several findings shows a lead line, then each finding as its own bullet with its sources, then the close ("The renewal is still set for Jan 25..."). The answer still writes itself word by word, bullet by bullet. The suggested next move under it is set in rose, with a rose bar before it, so the line to act on stands out; the bullet dots are rose too. Same on the desktop and the phone, and for every kind of question: the renewals answer lists one account per bullet, the promises answer one promise per bullet, and answers built from an account's record list each finding that stands out as a bullet.

**Why:** three findings in one paragraph were hard to read and harder to check against their sources.

**Checks:** bullets are a real list, so screen readers announce three items; the rose text is 5.6:1 on the light Ask box and 7.6:1 on the night one. Typecheck, lint and tests pass.

**Revisit if:** an answer has only one finding; it stays a paragraph (only marked pieces become bullets).
