# 0004 · Name: CRM Rethought for now

**Date:** 2026-11-05

**Decision:** the working title is CRM Rethought. A product name can come later.

**Options tried** (quick web searches, not trademark checks):

| Name | Result |
| --- | --- |
| Groundwork | Liked it; taken, including a "Groundwork CRM" and sales tools |
| Throughline | Used by a crisis support company and an investigations tool |
| Dealwork | Free, but felt narrow |
| Footing, Sure Footing | Free; did not click |
| Spadework | Close to a startup called SpadeWorks |
| Groundbrief | Free, but sounds like "ground beef" |
| Brief Game | Free, but every search result is a video game |
| SpadeAid, Spading | "Spade" is a funded AI data startup in finance |

**Why:** naming was eating time the research needs. A plain title says exactly what the project is.

**Revisit if:** a name comes up that is short, says what the product is for, and is free in software.
