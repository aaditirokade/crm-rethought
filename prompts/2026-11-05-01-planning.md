**Tool:** Claude (desktop app, with access to my portfolio repo)

### Prompt 1 · Planning
**Prompt:** "Take this existing CRM project and reimagine it from the ground up, like we did with Firstword, but the rethinking is about how AI could be integrated inside all the workflows. Reimagine the UI and basically everything. The case study has to have records of the prompts I'd write to AI and all the UX research steps; it should show how it was built by prompting LLMs in VS Code or the terminal, with the code on GitHub and a live prototype. This project will be public, so let's start planning. Give me all the step by step ideas."
**Why:** get a full plan before touching code.
**What came back:** a six phase plan (setup, research, define, design, build, test and tell), AI ideas for nine CRM workflows, a UI direction, a prompt log format, and a warning: the earlier CRM is under NDA, so a public copy is not safe.
**Kept / dropped:** kept the plan and the clean room rule; dropped duplicating the old project.
**My edit:** decided the new project starts from zero ([decision 0001](../decisions/0001-clean-room.md)).

### Prompt 2 · Strategy
**Prompt:** "I want to target the industry that makes most sense based on availability of jobs and H-1B visa transfer support in this market. Which industry would you suggest based on this?"
**Why:** the project should help me get hired, so its industry should match where design jobs are.
**What came back:** B2B enterprise SaaS, especially software for sales and customer teams, with fintech as a strong second; plus notes on H-1B transfers to confirm with a lawyer.
**Kept / dropped:** kept B2B SaaS account teams.
**My edit:** [decision 0002](../decisions/0002-industry.md).

### Prompt 3 · Research
**Prompt:** "We have to make up imaginary people to interview; no time to actually seek them out and interview them, unfortunately."
**Why:** time.
**What came back:** agreement, with rules: ground every persona in real public complaints, link each one, and label everything SIMULATED.
**Kept / dropped:** kept all of it.
**My edit:** [decision 0003](../decisions/0003-simulated-research.md).

### Prompt 4 · Naming (several rounds)
**Prompts, in order:**
1. "Think and suggest a good name for the app based on your judgment."
2. "Do a quick check and see if Groundwork is taken by another app. Also it needs something that says groundwork for what, like homework, but of what subject."
3. "Nah, Groundwork was nice. Is there anything close you can think of?"
4. "We can think of a combination of two words."
5. "How about Brief Game?"
6. "It sounds like ground beef, hahaha." (about Groundbrief)
7. "How is SpadeAid or Spading?"
8. "OK, let's just call it CRM Rethought for now and get going with the actual project."
**Why:** a name that says what the product is for and is free to use.
**What came back:** suggestions with quick web checks: Throughline, Dealwork, Footing, Spadework, Groundbrief, Sure Footing, Brief Game, and why each worked or didn't.
**Kept / dropped:** dropped all for now.
**My edit:** kept the working title ([decision 0004](../decisions/0004-name.md)). Lesson: naming can wait; research can't.

### Prompt 5 · Tooling
**Prompt:** "Is it worth setting up a Coder workspace with a personal subscription just to demo in interview rounds how I worked? Is there any edge in interviews from showing I've used a Coder workspace?"
**Why:** decide whether the tool itself adds anything.
**What came back:** no paid plan needed (Coder is free and open source); don't recreate past employer project structures; the edge is the proof (repo, prompts, live prototype), not the editor.
**Kept / dropped:** kept all of it.
**My edit:** [decision 0005](../decisions/0005-tooling.md).

### Prompt 6 · Setup
**Prompts:** "Should it be a new branch under my portfolio repo or a whole new repo?" · "What is npm install for?" · "What is git remote add origin?" · "I ran these commands but I don't see any files yet."
**Why:** first time setting up a project from scratch end to end, and I wanted to understand each step, not just paste it.
**What came back:** a new repo (its own app, its own Vercel project, no shared history with private work); plain explanations of each command. The first push failed because the GitHub address was never saved; once it was, the push worked.
**Kept / dropped:** kept the one repo, one branch (`main`) setup.
**My edit:** created the GitHub repo and connected Vercel myself. Live at [crm-rethought.vercel.app](https://crm-rethought.vercel.app/).
