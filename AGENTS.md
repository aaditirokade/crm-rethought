# Working rules for this repo

These apply to anyone working here, people and AI assistants alike.

1. **Clean room.** Nothing from any past employer: no screens, data, internal terms, metrics or workflows. See `decisions/0001-clean-room.md`.
2. **Label simulated work.** Every simulated persona, interview, quote or test is marked SIMULATED.
3. **Log prompts.** Each working session gets a file in `prompts/` with the prompts as written, what came back, what was kept and the author's edit.
4. **Record decisions.** One short file per decision in `decisions/`, listed in `decisions/README.md`.
5. **Updates log.** Every commit adds its message as one line under today's date in `updates.md`, in the same commit.
6. **Build the case study as we go.** At the end of each phase, update the "Case study" tab of the CRM Rethought plan doc (Claude Docs) with what the phase produced, with visuals wherever they help: personas, pain points, journey maps, flows, screens, test results.
7. **Accessibility.** WCAG AA in light and dark; check with axe before calling a screen done.
